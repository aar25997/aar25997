# NEFRA website: notes for Claude Code

Website for NEFRA ("Flavors of Civilization"), a premium fast-casual Mediterranean restaurant opening in Sterling, Virginia. Instagram: @nefrahouse. The site is a static site generated by `build.mjs` from JSON and Markdown content, edited by staff through Decap CMS at `/admin/`.

## Commands
- `node build.mjs`: build to `dist/` (no dependencies needed). Run it after every change; it must finish without errors.
- `npm run preview`: build and serve at http://localhost:8080
- `npm run photos`: place photos from `photos/` (see docs/PHOTO_SHOT_LIST.md)
- `npm run images`: regenerate responsive WebP versions (needs `npm install`)

## Where things live
- Content: `content/` (site.json, ordering.json, menu.json, locations.json, social.json, stories/*.md, events/*.md). **Prefer changing content over templates.** Prices, items, hours and locations must never be hard-coded in templates.
- Templates: `src/pages/*.html` (front matter + `{{component}}` tokens defined in `build.mjs`)
- Build modules: `lib/` (ordering.mjs is the only place that knows about ordering providers, schema.mjs builds JSON-LD)
- Styles: `src/assets/css/site.css`. Design tokens are at the top; use them, don't add literal colors.
- CMS fields: `src/admin/config.yml`. **When you add or rename a content field, update this file too.**
- Docs: `docs/HANDOFF.md`, `docs/ORDERING.md`, `docs/PHOTO_SHOT_LIST.md`

## Brand rules (from NEFRA's brief)
- Palette: Deep Emerald #0E5A4F (primary), Walnut #6B4A32, Matte Charcoal #232323, Antique Gold #B08D57 (accents only), Warm Stone #D7C9B6; neutrals Ivory #F7F4EE, Sand #E9E1D6, White.
- **Antique Gold must never be text on ivory, sand or emerald** (fails contrast). Use it for rules, borders and numerals, or as text on charcoal only.
- Type: Cinzel for display headings, Inter for body text.
- Feel: timeless, premium, earthy, modern, authentic, welcoming. Heritage through type, color and story, not Egyptian clichés (no pyramids or pharaohs). NEFRA is Mediterranean with Egyptian influence, not "an Egyptian restaurant".
- Use the official wordmark SVG for the logo once provided. Never recreate the logo or add new symbols.
- Motion stays subtle: fades only. No parallax, autoplaying audio or popups.

## Content rules: do not break these
- **No unverified claims.** Never label items or the restaurant "organic", "grass-fed", "allergen-free", "seed-oil-free", "halal", "gluten-free" or similar unless the owner confirms it for that specific product. Dietary tags and allergens go only on items where they are verified.
- **No invented facts.** Don't make up prices, addresses, hours, phone numbers, founder details, reviews or testimonials. Leave fields empty; the site shows "coming soon" text.
- Hours appear only when `hoursConfirmed` is true for that location.
- Testimonials only from real, verified reviews.
- Our Story is the founder's voice. Draft for review, and flag it, rather than publishing invented personal details.

## Ordering
- Provider-agnostic (Toast, Clover or SpotOn are under consideration). Every Order button resolves through `lib/ordering.mjs`.
- Ordering goes live only when a location has `status: "open"` and an ordering URL. Before that, buttons say "Get Opening Updates".
- Recommended mode is **link** (provider-hosted checkout). Never build custom payment handling.

## Quality bar
- Target WCAG 2.2 AA: keyboard access, visible focus, labeled forms, alt text on every photo, reduced-motion support, 4.5:1 text contrast.
- Mobile first: check 390px width. The page must never scroll sideways.
- Every page has one `h1`, a unique title and description, and headings in order.
- Keep structured data (`lib/schema.mjs`) consistent with what is visible on the page.
- Keep it fast: no frameworks or heavy libraries without a clear reason.
